# CLAUDE.md: Portent

Shake a real 3D magic 8 ball for a verdict, with the classic 20 answers or a deck imported from your own lists.

**Live:** portent.neorgon.com · **Port:** 8889

## Run

```bash
make serve
```

Then open http://localhost:8889. It must be served over HTTP: the app is ES modules, and `file://` blocks them.

## Data

- `localStorage['neokeys-prefs']`
- `localStorage['portentState']`

## Conventions

- Zero build step. Plain ES modules loaded by `js/app.js`.
- Header and footer come from the shared kits. Do not add site-local `.neo-footer` or `.header-bar` CSS.
- The fleet guideline is ~500 lines per module; `js/ball3d.js` is already past it. Split when touching it, do not grow it further.
